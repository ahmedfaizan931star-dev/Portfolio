Founder-built flagship · Active development

ArtifactLoop: software delivery as a complete system.

Most AI coding tools focus on generating code. ArtifactLoop is being built around the larger job: taking a request through planning, execution, testing, verification, repair and deployment—with evidence at each important step.

Open current product site
The problem

Building software is fragmented across planning notes, coding tools, task runners, testing, browser checks and deployment. A generated answer alone does not prove that a product works.

The approach

ArtifactLoop is designed as an AI software-production operating system: request → plan → execute → test → verify → repair → proof → deploy. The system is intended to make long-running work observable, resumable and accountable.

Engineering progress

The current foundation includes a PostgreSQL-backed job queue with lease and heartbeat handling, dependency-aware task execution, a problems engine and browser-agent workflows. Evidence-led verification, deeper repair loops and deployment proof remain part of the active build—not claims of a finished, launched platform.

How we work

A clear route from brief to handoff.

The exact plan depends on the project, but the working principles stay consistent: agree on the outcome, make progress visible and verify the important parts.

01

Discover

Understand the users, the problem, the current system and what a successful result should make possible.

02

Scope

Agree on priorities, requirements, technical direction, milestones and what is explicitly outside the first release.

03

Build

Implement in focused stages, share progress and surface trade-offs or risks before they become surprises.

04

Verify & hand over

Test the agreed flows, fix discovered issues and provide the agreed code, build, setup notes and handoff materials.

Depending on scope

What you can expect to receive

  • Written scope and priorities
  • Working preview or release build
  • Source code and setup notes, as agreed
  • Test and verification checklist
  • Clear handoff and next-step notes

Project estimates are scope-based. I confirm deliverables and milestones before work begins rather than quoting an arbitrary one-size-fits-all package.

PowerMate AI

Battery & charging diagnostics app

Problem

Most battery apps show raw percentage and little else, leaving users with no real sense of whether their charging habits are actually damaging long-term battery health.

Solution

Built a full charging command center: a live per-second monitor reading real Android battery sensors, charger/cable/stability scoring, separate care and health scores, an always-on-display mode, and configurable smart alerts for overheating, unstable chargers, and full-charge thresholds — all estimated entirely on-device, no login or cloud sync.

Result

A genuinely useful diagnostics app people would pay for, not just a percentage readout — backed by a working GitHub Actions CI/CD pipeline and a full UI/UX polish pass across typography, contrast, and navigation.

ScanMate AI Pro

Document scanning with OCR & AI workspace

Coming soon on Play Store

Problem

Paper documents need to be digitized, searchable, and sometimes protected — but most scanner apps stop at "take a photo" and leave organization, security, and text extraction to the user.

Solution

Built an offline-first document workflow on CameraX, ML Kit and Room/Flow: edge detection and auto-deskew, OCR, full-text search, PDF/TXT/DOCX/ZIP export, QR tools, AES-128-protected PDF export and a biometric-locked vault. Optional user-key AI workflows add document summarization and related assistance without making cloud sync or login a requirement for the core scanner.

Result

15 iterative hardening rounds added a broader document workflow: full-text search, protected PDF export, a biometric vault, business-card-to-vCard extraction and document quality checks. The 15-round figure describes the iteration history, not a third-party certification.

SpendWise

AI-powered expense & subscription tracker

Coming soon on Play Store

Problem

Recurring subscriptions and everyday spending quietly add up, and manually categorizing every purchase or typing in receipt details is tedious enough that most people just stop tracking.

Solution

Built an offline-first tracker where the Gemini API handles smart expense categorization and ML Kit OCR (carried over from ScanMate) reads receipts automatically, pulling amounts and merchant details without manual entry. All data stays local via Room — no cloud dependency.

Result

A fully offline expense and subscription tracker with automatic recurring-charge detection, shipped with a GitHub Actions CI/CD pipeline producing both debug and release builds.
